# NetMonitor Configuration & Schema Reference Manual

This technical manual details all configuration files, environment variables, device inventory schemas, and Prometheus target specifications utilized by the NetMonitor Enterprise platform.

---


## 2. Device Inventory JSON Schema (`data/db.json` & `devices.template.json`)

Each network device registered in the platform contains the following structured attributes:

```json
{
  "id": "dev-01",
  "name": "Core-Switch-01",
  "ip": "10.0.0.1",
  "type": "coreswitch",
  "category": "network",
  "vendor": "Cisco",
  "model": "Catalyst 9500-24Q",
  "location": "Main Data Center - Rack A01",
  "community": "public",
  "module": "cisco_switch",
  "isOnline": true
}
```

### Attribute Descriptions:
| Field | Type | Required | Description |
|---|---|---|---|
| `id` | String | Yes | Unique device identifier (e.g. `dev-01`, `uuid`) |
| `name` | String | Yes | Hostname or administrative display name |
| `ip` | String | Yes | Management IPv4 address (must be valid IPv4 format) |
| `type` | String | Yes | Functional topology role: `coreswitch`, `distswitch`, `switch`, `router`, `firewall`, `ap`, `server`, `ups`, `nas`, `other` |
| `category` | String | No | Category group: `network`, `security`, `wireless`, `compute`, `power`, `storage` |
| `vendor` | String | No | Manufacturer: `Cisco`, `Aruba`, `Huawei`, `MikroTik`, `Fortinet`, `Ruckus`, `APC`, `Synology`, `Linux`, `Windows` |
| `model` | String | No | Hardware model name |
| `location` | String | No | Physical building, room, or rack position |
| `community` | String | Yes | SNMPv2c Community String (Stored masked in Web UI) |
| `module` | String | Yes | SNMP Exporter profile: `if_mib`, `cisco_switch`, `cisco_sb`, `aruba_switch`, `huawei_switch`, `mikrotik_router`, `host_resources`, `apcups`, `synology` |

## 3. Dynamic Prometheus Target Schema (file_sd)

NetMonitor automatically synchronizes managed devices to Prometheus via dynamic `file_sd` YAML files.

### 3.1 Blackbox ICMP Ping Targets (`/etc/prometheus/targets/blackbox/netmonitor.yml`)
Strictly dedicated to network reachability and packet latency:
```yaml
# Auto-generated by NetMonitor Backend Server
# Job: blackbox-icmp
- targets:
    - '10.0.0.1'
    - '10.0.0.2'
  labels:
    job: 'blackbox-icmp'
    module: 'icmp'
```

### 3.2 SNMP Telemetry Targets (`/etc/prometheus/targets/snmp/netmonitor.yml`)
Dynamic module and auth routing per individual switch:
```yaml
# Auto-generated by NetMonitor Backend Server
# Job: snmp
- targets:
    - '10.0.0.1'
  labels:
    job: 'snmp'
    target: '10.0.0.1'
    module: 'cisco_switch'
    auth: 'public_v2'
    name: 'Core-Switch-01'
    type: 'coreswitch'
    vendor: 'Cisco'
    location: 'Main Data Center'
```

## 4. Supported SNMP Exporter Module Matrix

| Module Name | Target Hardware Family | Collected Metrics |
|---|---|---|
| **`if_mib`** | **Universal Standard (All Vendors)** | `ifHCInOctets` (64-bit In), `ifHCOutOctets` (64-bit Out), `ifOperStatus`, `ifAdminStatus`, `ifDescr`, `ifAlias`, LLDP Neighbors (`lldpRemSysName`) |
| **`cisco_switch`** | Cisco Catalyst 9000, 3850, 2960 (IOS / IOS-XE) | All `if_mib` metrics + CDP Neighbors (`cdpCacheDeviceId`), Cisco CPU (`cpmCPUTotal5minRev`), Cisco Memory (`ciscoMemoryPoolUsed`) |
| **`cisco_sb`** | Cisco Catalyst 1200/1300, CBS350, SG300/SG500 | All `if_mib` metrics + Radlan CPU (`rlCpuUtilDuringLast5Minutes`) |
| **`aruba_switch`** | HPE ProCurve, ArubaOS-S, CX 6200/6300 | All `if_mib` metrics + HP CPU (`hpSwitchCpuStat`), HP Memory (`hpSwitchMemoryAllocated`) |
| **`huawei_switch`** | Huawei CloudEngine, S5700, S6700 (VRP) | All `if_mib` metrics + Huawei CPU (`hwEntityCpuUsage`), Huawei Memory (`hwEntityMemUsage`) |
| **`mikrotik_router`** | MikroTik RouterOS (Cloud Core Router, Cloud Router Switch) | All `if_mib` metrics + CPU Load (`hrProcessorLoad`), Memory Storage (`hrStorageUsed`) |
| **`host_resources`** | Linux Servers, Windows Servers, KVM Hypervisors | CPU Load (`hrProcessorLoad`), System Memory & Disk Volume Usage (`hrStorageUsed`) |
| **`apcups`** | APC Smart-UPS, Symmetra | Battery Charge Percentage, Output Load, Internal Temperature, Battery Replacement Status |
| **`synology`** | Synology NAS DiskStation / RackStation | System Status, Disk Drive Health, Temperature, Storage Pool Space |

## 5. Universal PromQL Catalog (Used by NetMonitor Frontend)

| Purpose | PromQL Expression |
|---|---|
| **Device Reachability (Up/Down)** | `probe_success{job="blackbox-icmp"} == 1` |
| **Ping Latency (ms)** | `probe_duration_seconds{job="blackbox-icmp"} * 1000` |
| **Total Inbound Network Bandwidth** | `sum(rate(ifHCInOctets[2m])) * 8 / 1000000` *(Output in Mbps)* |
| **Total Outbound Network Bandwidth** | `sum(rate(ifHCOutOctets[2m])) * 8 / 1000000` *(Output in Mbps)* |
| **Multi-Vendor CPU Utilization (%)** | `hwEntityCpuUsage or cpmCPUTotal5minRev or rlCpuUtilDuringLast5Minutes or hpSwitchCpuStat or avg by(instance)(hrProcessorLoad)` |
| **Active Network Interfaces Count** | `count by (instance)(ifOperStatus == 1)` |
